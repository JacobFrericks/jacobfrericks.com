# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub:
[Report a vulnerability](https://github.com/JacobFrericks/jacobfrericks.com/security/advisories/new).

Do not open a public issue for a security problem.

I aim to reply within 7 days. Please include what you found, how to reproduce it, and the impact you expect.

## Scope

- The live site at https://www.jacobfrericks.com
- The build, signing, and deploy workflows in `.github/workflows`
- The release bundles and their SLSA provenance

Only the latest release and the `main` branch are supported.
